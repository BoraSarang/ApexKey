기능 사용법 다운로드 GitHub

macOS 메뉴바 유틸리티 · macOS 14+

어떤 앱의 메뉴 명령도
전역 단축키로.

ApexKey는 메뉴바에 상주하며, 화면 어디에서나 다른 앱의 메뉴 명령·URL scheme·나만의 동작을 한 번의 단축키로 실행하게 해줍니다.

무료 다운로드 기능 살펴보기
⌥+⇧+A 패널 열기/닫기

모든 것이 단축키로.

반복되는 메뉴 클릭을 줄이고, 키보드에서 손을 떼지 마세요.

⚡

메뉴 명령 단축키

실행 중인 앱의 메뉴 항목을 열거해 원하는 명령에 전역 단축키를 지정하세요.

📦

동작 스테이션

앱 열기 · 키 입력 · 스크립트 · 붙여넣기를 단계로 쌓아 나만의 동작을 만듭니다.

🔗

URL Scheme

어떤 scheme이든 단축키 하나로 즉시 엽니다.

🧭

메뉴 단축키 HUD

현재 앱의 모든 단축키를 전체화면·플로팅으로 한눈에 표시합니다.

🔀

흐름 제어·자동화

If · 반복 · 메뉴 선택, 변수, 시간·폴더 조건 기반 트리거까지.

🎨

8가지 테마

라이트·다크·네온·노드·페이퍼·터미널·오사우루스 — 폰트 크기까지.

3단계로 시작

  1. 1

    설치 & 권한

    Releases에서 받아 응용 프로그램에 넣고, 손쉬운 사용 권한을 허용합니다.

  2. 2

    단축키 지정

    ⇧⌥A 로 패널을 열고, 앱의 메뉴 명령에 + 를 눌러 녹음합니다.

  3. 3

    바로 실행

    어디서든 그 단축키를 누르면 메뉴 명령이 실행됩니다. ⇧⌥S 로 HUD 표시.
