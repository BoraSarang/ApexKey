- [ ] ⬜ 사이보그 모드(`pauseUntilInput`) 실행 → `⌘⇧↩`로 **정상 해제되는지**
      (실행이 직렬 큐로 바뀌면서 대기 상태가 깨질 수 있는 지점)
- [ ] ⬜ 자동화 트리거(시간 조건)가 **정상 발동하는지** — `shortcutProvider`가
      이제 메인으로 한 번 홉한다. 지연이 체감되는지
- [ ] ⬜ Run Shortcut(하위 단축어 호출)이 **여전히 동작하는지**
- [ ] ⬜ 실행이 끝난 뒤 **통계(실행 횟수·마지막 실행 시각)가 정확히 1회만 증가하는지**
- [ ] ⬜ 토스트가 실행 완료 시점에 정상 표시되는지
- [ ] ⬜ 핫키를 **연속으로 여러 번** 눌러도 실행이 직렬로 처리되는지 (겹쳐 실행 안 됨)

### 8-8. 텍스트/데이터 액션 23종 설정 UI (T-171·T-172)

> 순수 로직과 엔진 배선은 테스트로 고정했다(합계 100건 이상).
> **하지만 "UI에서 설정한 값이 `actionParameters`에 저장되고 실행에 반영되는지"는
> 자동 검증 범위 밖이다.** 카탈로그에 23종이 정상이 나타나는 것은 빌드 성공의 증거일 뿐이다.

- [ ] ⬜ 카탈로그에서 **정규식** 선택 → 설정 창에 "찾을 문자열 또는 패턴" 입력 → 실행
- [ ] ⬜ **정규식**에서 "바꿀 문자열"을 채우면 치환 모드로 바뀌는지 (안 채우면 매치 추출)
- [ ] ⬜ **정렬**에서 방식(사전순/숫자순)·순서(오름/내림) 바꾼 뒤 실행
- [ ] ⬜ **대소문자** 6종 스타일 각각 확인
- [ ] ⬜ **계산**에 `2+3*4` 입력 → 14, `(2+3)*4` → 20
- [ ] ⬜ **계산**에 잘못된 식(`2+`) 입력 → **"수식 형식이 올바르지 않습니다"** 표시 (빈 결과 아님)
- [ ] ⬜ **계산**에 `1/0` → **"0으로 나눌 수 없습니다"** 표시
- [ ] ⬜ **수학**에서 연산·구분자 바꿔 가며 동작
- [ ] ⬜ **Base64** 인코딩→디코딩 왕복
- [ ] ⬜ **해시** SHA-256/SHA-512 결과가 64/128자리
- [ ] ⬜ **UUID** 개수 5 → 줄바꿈으로 5개
- [ ] ⬜ **날짜 형식**에 `yyyy-MM-dd HH:mm:ss` → 현재 시각으로 표시
- [ ] ⬜ **클립보드 가져오기/설정** — 실제 클립보드로 왕복
- [ ] ⬜ 설정 값 저장 후 **앱 재시작 → 유지되는지**
