## 문서 건강 상태 (2026-09-29 기준)

### 알려진 결함 — 앰벳을 옮기지 않았습니다

| 문제 | 영향 | 상태 |
|---|---|---|
| `FUNCTIONAL_CHECKLIST.md` §6은 날짜가 찍힌 감사 스냅샷 | 시간이 지나면 이미 고친 항목을 미해결로 보여 준다 (실제로 그랬다) | 각 행에 커밋 해시·상태를 병기하는 방식으로 완화. 구조 변경은 미착수 |
| **`check-localizable.py`는 키 존재를 검사하지 않는다** | 없는 키는 게이트를 통과하고 UI에 원문 키로 노출된다 | **코드로 보완하지 않음.** 수동 확인 절차로만 막을 수 있다. 2026-09-29에 `missing\|exists\|not in` 검색으로 재확인 |
| **`JSONEncoder`는 기본 키 순서가 비결정적** | 프로세스를 넘기면 같은 값의 바이트가 달라진다. **비교**에 쓰면 잠금 판정이 어긋난다 | `StoreCoding`이 `.sortedKeys`로 고정 (E-MAC-STORE-5012). 새 코드는 `StoreCoding`만 쓸 것 |
| **캐시된 빌드는 경고를 숨긴다** | 점진 빌드로 "경고 0"처럼 보인다. 실제로 클린 빌드에 13건이 있었다 | **해결**(T-183, 현재 경고 0). 그래도 `xcodebuild clean build`로만 확인할 것 |
| `TODO.md`가 400줄 이상으로 완료 이력이 대부분 | 미해결 8건을 찾으려면 끝까지 스크롤해야 한다 | 최상단에 요약 인덱스 + `[~]` 무효화 표기 도입 |
| `plans/` 28개 | 완료된 계획이 다수 | 각 파일에 status가 있으니 그것으로 충분하다고 판단 |

## 규칙 문서(`~/.config/opencode/rules/`)는 프로젝트 밖이다

`rules/quality.md`는 사용자 메시지를 `error_message_ko.json`에 두라고 요구하지만
**그 파일이 존재하지 않는다.** 현재는 `Localizable.strings`의 `error.user.*` 키가
ko/en 모두 포함해 있어 기능적으로 우월하다.

`~/.config/opencode/rules/`는 프로젝트 밖이라 **사용자 지시 없이 수정하지 않는다.**
예외 조항 추가 여부는 사용자가 결정할 사항이다.
