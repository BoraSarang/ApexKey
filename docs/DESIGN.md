# ApexKey — 디자인 (DESIGN)

## 1. 앱 아이덴티티

- **이름**: ApexKey (한국어: 애펙스키)
- **컨셉**: "나만 있으면 다 돼" — 최상위(정점)에 오른 글로벌 단축키
- **번들ID**: `com.borasarang.ApexKey`

---

## 2. 아이콘 컨셉 — "정점(Pinnacle)에 오른 단축키"

### 2.1 앱 아이콘 (1024px)
- 배경: 청록(#30C5A0) → 보라(#6C5CE7) **대각선 그라데이션**, 부드러운 라운드 사각
- 중앙: **산(△) 정상 꼭대기**에 금색 **⌘(커맨드) 키 캡**
- 의미: 최상위(산 정상)에 있는 커맨드 키 = ApexKey

### 2.2 메뉴바 템플릿 아이콘 (16px, 단색)
- 라이트/다크 자동 반전 템플릿
- **▲ 상승 화살표 + ⌘** 조합 — "최상위 커맨드" 직관
- SF Symbol 후보: `command.square.fill`, `arrow.up.to.line.compact`

## 3. UI/UX

- macOS 메뉴바 앱 (Dock 미표시, `LSUIElement`)
- Material/배경: macOS 14 표준 material (Liquid Glass는 macOS 26 자동 대응)
- 반응형: 다크/라이트 모드 지원

### 3.1 메인 패널
- 좌측 사이드바(기능 탭) + 우측 콘텐츠(앱 리스트)
- 앱 행: 아이콘 + 이름 + 설정 여부(🟢/⚪) + 개수 + [설정]
- 도구 탭 2종: **워크플로우**(동작 스테이션, "프리셋 추가"로 시스템 9종을 1단계 워크플로우로 확장) · **자동화**(트리거 목록/추가/편집) — 시스템 탭은 v0.8에서 프리셋 통합으로 제거됨

### 3.2 앱 상세
- 상단: 설정된 글로벌 단축키 (추가/삭제)
- 하단: AXUIElement로 열거한 앱 메뉴 단축키 (중복 ⚠️)

### 3.3 키 레코더
- 키 입력 표시 + 저장/취소
- "선택 앱 활성 시 실행" 옵션

### 3.4 메뉴바·Dock 표시 정책 (T-226, 2026-11-19)
- 기본값: **메뉴바 아이콘 표시**, Dock 미표시(`LSUIElement` + `.accessory`)
- 두 아이콘을 **모두 끄는 것을 허용**한다. 전역 단축키는 상태 아이템과 독립이라 계속 동작한다
- 복구 경로는 **재실행 → 설정 창**이다 (PopClip 2025.9과 같은 방식)
  - 이미 실행 중: Finder·Spotlight·Dock에서 `.app`을 다시 열면 `applicationShouldHandleReopen`이 설정 창을 연다
  - 꺼져 있음: 수동 실행이면 설정 창 1회, 로그인 자동 시작이면 숨김 유지
- 마지막 아이콘을 끌 때 1회 확인 알림. 설정 창에 **ApexKey 종료** 버튼과 "아이콘 없이 실행 중" 안내를 둔다
- 임시 아이콘 복원(PopClip 2021)은 채택하지 않는다 — Bartender/Ice가 가리면 복구가 실패하고, 숨김 타이머가 필요하다
