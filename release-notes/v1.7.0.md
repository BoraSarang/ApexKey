# ApexKey v1.7.0

> v1.6.0은 배포되지 않았습니다. 이 버전은 v1.5.0 이후의 변경(트랙패드 포함)을 모두 담습니다.

## 새로운 기능

### 트랙패드 제스처 (기본 꺼짐)

- **에지 슬라이더** — 트랙패드 오른쪽 에지를 두 손가락으로 위아래로 밀면 볼륨이 조절됩니다. HUD에 ▲/▼가 표시됩니다.
- **탭·스와이프 제스처** — 여러 손가락 탭과 스와이프를 워크플로우·단축키·메뉴 항목·시스템 액션에 연결할 수 있습니다.
- **미리보기** — 설정 화면에서 손가락 위치와 인식 상태를 실시간으로 확인할 수 있습니다.
- 스크롤 억제는 기존 **손쉬운 사용** 권한을 재사용합니다. 별도 승인 창은 없습니다.
- 사이드바 **도구 → 트랙패드**에서 토글을 켜야 동작합니다.

### 실행 가능한 액션 48종 추가 (카탈로그 154종 중 100종 구현)

- **이미지 인식** — `텍스트 인식(OCR)`·`QR 코드 스캔`·`동물 인식`. 파일 경로를 지정하거나 비워 두면 클립보드 이미지를 사용합니다.
- **언어·수치·날짜** — `언어 감지`, `측정`(길이·질량·온도·부피 단위 변환), `날짜 조정`, `날짜/시간 입력`.
- **대화상자** — `대화상자`(텍스트 입력), `확인 가져오기`(확인 시 `true`, 취소 시 `false` 출력), `빠르게 보기`.
- **프로세스·데이터·파일** — `잠자기 방지`(ApexKey 종료 시 자동 해제), `딕셔너리 가져오기`(JSON/plist, 점 표기 중첩 키), `리스트 동작`, `출력 저장`.
- **시스템 프리셋 7종 승격** — `스크린샷`·`새 메모`·`새 빠른 메모`·`배경화면`·`화면 깨우기`·`앱을 앞으로`·`다크 모드`를 개별 액션 행에서 바로 선택·실행할 수 있습니다.

### 파일 액션 7종

- **목록·이동·이름 변경** — `파일 가져오기`(하위 폴더·숨김·확장자 필터), `파일 이동`(대상 폴더 자동 생성), `이름 변경`(`{name}`·`{index}`·`{date}`·`{ext}` 템플릿, 확장자 보존).
- **압축·외부 저장소·파일 동작** — `압축 풀기`(zip은 `ditto`, tar 계열은 `tar`), `외부 저장소`(볼륨 목록·복사), `파일 동작`(복제·휴지통·Finder에서 보기).
- **첨부 저장** — `메일`의 선택 메시지 첨부를 폴더에 저장합니다.
- **안전장치** — 데이터를 바꾸는 동작은 확인 창이 기본으로 켜져 있고, 취소하면 원본을 그대로 둡니다.

### Apple 앱 연동 16종

- **메모·미리 알림·캘린더** — 메모 생성/덧붙이기/열기/폴더 만들기, 미리 알림 추가·목록 이름, 일정 추가·캘린더 이름.
- **메일** — 새 초안, 열린 초안의 본문·수신자 변경, 이전 단계 데이터를 본문·첨부로. **기본은 초안 열기**이며 `바로 보내기`를 켰을 때만 발송합니다.
- **음악·팟캐스트** — 곡/아티스트 검색, 재생목록 재생. Podcasts는 AppleScript 사전이 없어 앱 열기와 URL 재생만 지원합니다.
- **사진** — 최근 사진 목록, 원본 내보내기(파일 경로 출력), 최근 사진·앨범 열기, 무작위 사진, 앨범 만들기·목록.
- 모든 Apple 앱 액션은 첫 실행 시 macOS 자동화 승인을 한 번 요청합니다.

### 문서 앱 4종

- **TextEdit** — 새 문서(본문 포함), 문서 열기, 본문 덧붙이기/전체 바꾸기, 글꼴·크기 지정.
- **Pages·Numbers** — 표준 열기/새 문서만 지원합니다. 미설치면 "앱 미설치" 사유를 표시합니다.
- 본문 편집과 글꼴 지정은 TextEdit 전용이며, 다른 앱은 지원하지 않는다고 알립니다.

### 자동화 트리거 4종 추가 (지원 4종 → 8종)

- **파일 변경** — 대상 파일의 부모 폴더를 감시하고, 해당 파일이 바뀔 때 발동합니다.
- **외장 드라이브** — USB·외장 디스크 연결/분리. 드라이브 이름으로 필터할 수 있습니다.
- **디스플레이** — 외부 모니터 연결/분리. 해상도만 바뀌면 발동하지 않습니다.
- **앱** — 대상 앱의 실행·종료·활성·비활성. 번들 ID로 필터합니다.
- 설정 화면에서 경로·드라이브 이름·번들 ID와 이벤트를 직접 고를 수 있습니다.

## 수정

- **카탈로그 정직성** — 시스템 동작으로 이미 실행되던 7종이 "준비 중"으로 보이던 문제를 고쳤습니다.
- **중복 액션 정리** — `스크린샷 찍기`(→ `스크린샷`), `클립보드 텍스트`(→ `클립보드 가져오기`/`클립보드 설정`)가 두 번 보이지 않습니다.
- **OneDrive 표시 이름** — 다른 드라이브와 같은 이름으로 표시되던 문제를 분리했습니다.
- **트랙패드 방향·인식** — 좌표계 뒤집힘과 과도한 스텝을 수정했습니다.
- **자동화 배지** — 배지 수를 실제 등록 수 기준으로 계산합니다.

## 설치 방법

1. 아래 `ApexKey-1.7.0-macOS.dmg`를 다운로드합니다.
2. DMG를 열어 ApexKey를 응용 프로그램 폴더로 드래그합니다.
3. 첫 실행 시 **우클릭 → 열기**로 실행하세요.
   (공증되지 않은 앱이라 Gatekeeper가 첫 실행을 차단합니다.)

## How to install

1. Download `ApexKey-1.7.0-macOS.dmg` below.
2. Drag ApexKey to Applications.
3. On first launch, **right-click → Open**.
   (Gatekeeper blocks unsigned apps on first launch.)

## 알려진 제약 (릴리스마다 포함)

> 배포본이 코드 서명·공증되지 않은 상태라 사용자가 반드시 겪는 동작입니다.
> 매번 복사해 넣으세요. 서명 도입 시 이 절을 삭제합니다.

### ⚠️ 릴리스는 코드 서명·공증되지 않았습니다

- **첫 실행 차단** — Gatekeeper가 앱을 막습니다. **우클릭 → 열기**로 우회하세요.
- **업데이트마다 접근성 권한 재승인** — 새 버전 설치 후에는
  시스템 설정 → 개인정보 보호 → 손쉬운 사용에서 ApexKey를 다시 켜야 합니다.
  macOS가 접근성 권한을 앱의 코드 서명(CDHash)에 묶어 두는데, 무서명 앱은 버전마다 이 값이
  바뀌어 권한이 자동 해제되기 때문입니다. Developer ID 서명·공증으로 해결됩니다.
- **트랙패드 제스처는 기본 꺼짐** — 설정 → 트랙패드에서 직접 켜야 합니다.
- **Apple 앱 연동은 자동화 승인 필요** — 메일·메모·미리 알림·캘린더·음악·사진·문서 앱을 처음 제어할 때
  macOS가 승인을 한 번 요청합니다. 거부하면 시스템 설정 → 개인정보 보호 및 보안 → 자동화에서 허용하세요.
