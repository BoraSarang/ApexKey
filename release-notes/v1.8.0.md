# ApexKey v1.8.0

> v1.6.0은 배포되지 않았습니다. 이 버전은 v1.5.0 이후의 변경(트랙패드·1차·2차·3차)을 모두 담습니다.
> v1.7.0에서 예고한 "다음 버전" 항목 중 공개 API로 가능한 것을 마무리했습니다.

## 새로운 기능

### 시스템 제어 2종

- **Wi-Fi** — 상태 확인·켜기·끄기. macOS 공개 CLI(`networksetup`)만 사용하고, 설정 후 실제 상태를 다시 읽어 확인합니다.
- **집중 모드** — Shortcuts 앱에서 만든 "집중 모드 설정" 단축어를 이름으로 실행합니다. 집중 모드는 공개 스크립팅 API가 없어 단축어를 경유합니다.

### 미디어 편집·캡처 7종

- **이미지** — `이미지 회전`·`이미지 자르기`. CoreImage로 처리하고 **원본은 바꾸지 않습니다**, `이름-rotated.png`처럼 파생 파일로 저장합니다.
- **비디오** — `비디오 자르기`. macOS 기본 `avconvert`로 시작·길이를 지정해 새 파일로 내보냅니다.
- **카메라** — `카메라`로 사진을 촬영해 사진 폴더(또는 지정 폴더)에 저장합니다. 첫 실행 시 카메라 권한을 한 번 요청합니다.
- **미디어 제어** — `미디어 볼륨`(0~100%), `현재 곡 이동`(확인 후 이동), `음악`(재생·일시정지·다음/이전 곡·정지).

### 콘텐츠·위치·웹 8종

- **메시지** — iMessage로 발송합니다. 기본은 **보내기 전 확인**이며, 취소하면 보내지 않습니다.
- **이메일** — Mail 초안을 엽니다. `바로 보내기`를 켰을 때만 발송합니다.
- **지도·대중교통** — Apple 지도에서 길찾기를 엽니다(운전·도보·대중교통).
- **웹 콘텐츠** — 공개 http/https 페이지의 제목이나 본문 텍스트를 읽습니다. 로그인 페이지는 빈 내용 사유를 돌려줍니다.
- **웹 연동** — 페이지 가져오기, URL 인코딩·디코딩. `file://` 등은 거부합니다.
- **프레젠테이션** — Keynote 발표 시작·중지. 미설치면 "앱 미설치" 사유를 표시합니다.
- **단축어 아이콘** — SF Symbol과 배경색으로 1024×1024 PNG를 만듭니다.

### App Intents·자동화 카탈로그 7종

- **앱 찾기** — 설치 앱을 이름 또는 번들 ID 일부로 검색합니다.
- **App Intent** — Shortcuts 앱에서 App Intent를 감싼 단축어를 이름으로 실행합니다. 입력 텍스트는 임시 파일로 전달합니다.
- **App 동작** — 앱의 URL scheme(`shortcuts://`, `music://` 등)을 열어 동작을 실행합니다.
- **자동화·자동화 찾기** — ApexKey 단축어에 등록된 트리거를 나열·검색합니다. 준비 중 트리거는 숨길 수 있습니다.
- **자동화 실행** — 저장된 단축어를 이름으로 실행합니다.
- **트리거** — 지정한 트리거가 실제로 등록된 단축어만 지금 실행합니다(테스트용).

### 사용자 변수 이름 토큰 `{이름}`

- UUID 대신 **변수 이름**으로 값을 참조할 수 있습니다. 예: `안녕, {이름}!`
- 숨김 변수는 노출하지 않고, 같은 이름의 특수 변수(`{clipboard}` 등)가 있으면 특수 변수가 우선합니다.
- 하위 단축어를 실행해도 안쪽 변수 이름이 바깥으로 새지 않습니다.

## 정리·수정

- **영구 제외 확정** — `동영상 다운로드`·`AirDrop`·`최근 항목 지우기`·`블루투스`는 공개 API가 없거나 법적 위험이 있어 **카탈로그에서 숨겼습니다**. "다음 버전" 목록에도 다시 나오지 않습니다.
- **미구현 표기 정직성** — 구현되지 않은 27종은 카탈로그에서 "준비 중"으로만 보이고 선택되지 않습니다.
- **중복 정리** — `스크린샷 찍기`는 `스크린샷`으로, `클립보드 텍스트`는 클립보드 액션으로 통합된 상태를 유지합니다.
- **플랫폼 백로그 문서화** — macOS 14 실기 검증·Developer ID 서명·`error_message_ko.json` 규칙은 사용자·환경 대기 항목으로 절차와 완료 기준을 문서에 남겼습니다.

## 설치 방법

1. 아래 `ApexKey-1.8.0-macOS.dmg`를 내려받습니다.
2. ApexKey를 Applications 폴더로 옮깁니다.
3. 첫 실행 시 **우클릭 → 열기**로 실행하세요.
   (공증되지 않은 앱이라 Gatekeeper가 첫 실행을 차단합니다.)

## How to install

1. Download `ApexKey-1.8.0-macOS.dmg` below.
2. Drag ApexKey to Applications.
3. On first launch, **right-click → Open**.
   (Gatekeeper blocks unsigned apps on first launch.)

## 알려진 제약 (릴리스마다 포함)

> 배포본이 코드 서명·공증되지 않은 상태라 사용자가 반드시 겪는 동작입니다.
> 매번 복사해 넣으세요. 서명 도입 시 이 절을 삭제합니다.

### ⚠️ 릴리스는 코드 서명·공증되지 않았습니다

- **첫 실행 차단** — Gatekeeper가 앱을 막습니다. **우클릭 → 열기**로 우회하세요.
- **업데이트마다 접근성 권한 재승인** — 새 버전 설치 후에는
  시스템 설정 → 개인정보 보호 → 손쉬운 사용에서 ApexKey를 다시 켜야 합니다.
  macOS가 접근성 권한을 앱의 코드 서명(CDHash)에 묶어 두는데, 무서명 앱은 버전마다 이 값이
  바뀌어 권한이 자동 해제되기 때문입니다. Developer ID 서명·공증으로 해결됩니다.
- **트랙패드 제스처는 기본 꺼짐** — 설정 → 트랙패드에서 직접 켜야 합니다.
- **Apple 앱 연동은 자동화 승인 필요** — 메일·메모·미리 알림·캘린더·음악·사진·문서·메시지·Keynote를
  처음 제어할 때 macOS가 승인을 한 번 요청합니다. 거부하면 시스템 설정 → 개인정보 보호 및 보안 → 자동화에서 허용하세요.
- **카메라는 별도 권한** — `카메라` 액션 첫 실행 시 카메라 접근을 요청합니다. 거부하면
  시스템 설정 → 개인정보 보호 및 보안 → 카메라에서 허용하세요.
- **Shortcuts 단축어가 필요합니다** — 집중 모드와 App Intent 액션은 사용자가 Shortcuts 앱에서
  만든 단축어를 이름으로 실행합니다. App Intent를 직접 호출하는 공개 런타임 API가 없기 때문입니다.
