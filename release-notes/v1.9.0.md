# ApexKey v1.9.0

> v1.8.1은 배포되지 않았습니다. 이 버전은 v1.8.0 이후 변경(볼륨 HUD·무아이콘 모드·트랙패드 v2·밝기)을 모두 담습니다.

## 새로운 기능

### 트랙패드 v2 (기본 꺼짐)

인식 계층을 처음부터 다시 만들었습니다. 기본 규칙은 macOS가 이미 쓰지 않는 입력만 씁니다.

- **에지 슬라이더** — 오른쪽 에지를 **한 손가락**으로 위아래로 밀어 볼륨을 연속 조절합니다. 감도 1.5, 진입 띠 7%, 시작 임계 1.5%가 기본값입니다.
- **수정자 레이어** — ⌃·⌥·⌘를 누른 채 슬라이드하거나 제스처를 하면 **그 조합에 맞는 규칙만** 실행됩니다. 수정자가 없는 규칙과 섞이지 않습니다.
- **이산 제스처** — 4손가락 탭, 5손가락 스와이프를 기본 제공합니다. 3/4손가락 스와이프는 macOS 제스처와 충돌하므로 경고를 확인한 뒤 고급 설정에서 켭니다.
- **커서 고정** — 1손가락 슬라이드 중에는 커서가 움직이지 않고, 손을 떼면 원래 자리로 돌아옵니다.
- **즉시 스크롤 억제** — 손가락이 에지를 따라 움직이기 시작하는 순간부터 페이지 스크롤을 막습니다. 에지에 스치기만 하면 막지 않습니다.
- **햅틱** — 1/16 단위로 손끝에 걸리는 느낌을 줍니다.
- **빈 상태 안내** — 설정 → 트랙패드에서 **권장 설정 불러오기**로 바로 시작할 수 있습니다.

### 밝기

- 에지 슬라이더 대상에 **밝기**를 추가했습니다. 내장 디스플레이 밝기를 연속으로 바꾸고, HUD에 해 아이콘과 %를 표시합니다.
- 밝기를 지원하지 않는 환경에서는 규칙 편집 시 경고가 뜨고 실제로 실행되지 않습니다. 앱과 다른 규칙은 정상 동작합니다.

### 무아이콘 모드

- 메뉴바와 Dock 아이콘을 **모두 꺼도** 전역 단축키가 그대로 동작합니다.
- 아이콘이 없는 상태에서 앱을 다시 열면 설정 창이 뜹니다. 설정 창의 **ApexKey 종료** 버튼으로 종료할 수 있습니다.

### 시스템 볼륨 HUD

- 볼륨 올리기·내리기·음소거가 macOS **네이티브 볼륨 HUD**를 표시합니다. 음소거는 볼륨 값을 보존하는 실제 음소거 플래그를 씁니다.

## 수정

- **트랙패드 억제가 남던 문제** — 손을 뗀 뒤에도 0.5초 동안 스크롤이 막히던 문제를 고쳤습니다.
- **볼륨 경계 반응** — 100%/0%에서 더 민 뒤 반대로 밀 때 한참 반응이 없던 문제를 절대값 계산과 경계 클램프로 고쳤습니다.
- **에지 슬라이더 기본값** — macOS 스크롤·알림 센터와 겹치던 2손가락 기본 규칙을 1손가락·오른쪽 에지로 바꿨습니다. 기존에 직접 만든 규칙은 그대로 유지되고, v0.33 기본값 그대로인 규칙만 한 번 새 권장값으로 보정됩니다.

## 업그레이드 안내

- 트랙패드 기능은 **기본 꺼짐**입니다. 설정 → 트랙패드에서 켜야 동작합니다.
- 기존 트랙패드 규칙은 저장된 그대로 남습니다. 다만 v0.33 기본값(2손가락·에지 폭 15% 등)을 바꾸지 않은 규칙은 새 기본값으로 한 번 보정됩니다.
- 밝기는 **내장 디스플레이**에서 동작합니다. 자동 밝기 조절이 켜져 있으면 macOS가 슬라이더 값을 일부 덮어쓸 수 있습니다.

## 설치 방법

1. 아래 `ApexKey-1.9.0-macOS.dmg`를 다운로드합니다.
2. DMG를 열어 ApexKey를 응용 프로그램 폴더로 드래그합니다.
3. 첫 실행 시 **우클릭 → 열기**로 실행하세요.
   (공증되지 않은 앱이라 Gatekeeper가 첫 실행을 차단합니다.)

## How to install

1. Download `ApexKey-1.9.0-macOS.dmg` below.
2. Drag ApexKey to Applications.
3. On first launch, **right-click → Open**.
   (Gatekeeper blocks unsigned apps on first launch.)

## 알려진 제약

### ⚠️ 릴리스는 코드 서명·공증되지 않았습니다

- **첫 실행 차단** — Gatekeeper가 앱을 막습니다. **우클릭 → 열기**로 우회하세요.
- **업데이트마다 접근성 권한 재승인** — 새 버전 설치 후에는
  시스템 설정 → 개인정보 보호 → 손쉬운 사용에서 ApexKey를 다시 켜야 합니다.
  macOS가 접근성 권한을 앱의 코드 서명(CDHash)에 묶어 두는데, 무서명 앱은 버전마다 이 값이
  바뀌어 권한이 자동 해제되기 때문입니다. Developer ID 서명·공증으로 해결됩니다.

### 트랙패드

- **수정자는 macOS 제스처를 막지 않습니다.** ⌥를 눌러도 3/4손가락 스와이프의 Mission Control은 그대로 발동할 수 있습니다. 충돌하는 규칙은 경고와 함께 시스템 설정 안내를 제공합니다.
- **진입 띠 7%** — 손가락이 에지 띠 밖에서 시작하면 동작하지 않습니다. 커서 이동과 구분하기 위한 의도된 동작이며, 규칙별 고급 설정에서 4~25%로 조절할 수 있습니다.
- **밝기 API** — 내장 디스플레이 밝기는 비공개 프레임워크에 의존합니다. macOS 업데이트로 API가 바뀌면 밝기만 비활성화되고 앱은 정상 동작합니다.
