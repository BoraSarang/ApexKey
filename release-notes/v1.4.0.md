# ApexKey v1.4.0

## 새로운 기능

- **메뉴바 아이콘 그리드** — 노치 뒤에 숨은 것까지 모든 상태 아이콘을 한 그리드에 모아 실제 아이콘을 클릭합니다. `⌥⌘]`로 열기, Space 좌클릭·Return 우클릭(뒤바꿈 가능), 메뉴바 우클릭 메뉴에서도 진입
- **Menu HUD 드릴인** — 서브메뉴를 제자리에서 파고들고 breadcrumb으로 되돌아가기. HUD가 포인터 옆에 뜹니다
- **첫 실행 가이드** — 권한 + 단축키 확인을 2분 안에, 각 단축키는 ▶ 직접 실행으로 눌러보기
- **단축키 안전장치** — 켜진 macOS 시스템 단축키와 겹치면 경고 후 이동/강행/취소. 실패한 메뉴 실행은 원인 토스트 표시
- **설정 8탭 개편** — 기능별 탭 + 탭마다 도움말 카드(뭐고·언제·이렇게). 단축키 행에서 ▶ 직접 실행·↺ 복원
- Option 대체항목(Close All 등) 중복이 HUD에서 정리됩니다

## 수정

- 메뉴바 아이콘 열거가 Safari WebContent 응답 대기로 수 초 멈추던 문제 — 병렬 조회 + 캐시 + 예열로 해결
- 온보딩 창 닫기 경로 정리, 설정 창 단축키 시트 통합

## 설치 방법

1. 아래 `ApexKey-1.4.0-macOS.dmg`를 다운로드합니다.
2. DMG를 열어 ApexKey를 응용 프로그램 폴더로 드래그합니다.
3. 첫 실행 시 **우클릭 → 열기**로 실행하세요.
   (공증되지 않은 앱이라 Gatekeeper가 첫 실행을 차단합니다.)

## How to install

1. Download `ApexKey-1.4.0-macOS.dmg` below.
2. Drag ApexKey to Applications.
3. On first launch, **right-click → Open**.
   (Gatekeeper blocks unsigned apps on first launch.)

## 알려진 제약 (릴리스마다 포함)

> 배포본이 코드 서명·공증되지 않은 상태라 사용자가 반드시 겪는 동작입니다.
> 매번 복사해 넣으세요. 서명 도입 시 이 절을 삭제합니다.

### ⚠️ 릴리스는 코드 서명·공증되지 않았습니다

- **첫 실행 차단** — Gatekeeper가 앱을 막습니다. **우클릭 → 열기**로 우회하세요.
- **업데이트마다 접근성 권한 재승인** — 새 버전 설치 후에는
  시스템 설정 → 개인정보 보호 → 손쉬운 사용에서 ApexKey를 다시 켜야 합니다.
  macOS가 접근성 권한을 앱의 코드 서명(CDHash)에 묶어 두는데, 무서명 앱은 버전마다 이 값이
  바뀌어 권한이 자동 해제되기 때문입니다. Developer ID 서명·공증으로 해결됩니다.
