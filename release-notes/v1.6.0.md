# ApexKey v1.6.0

## 새로운 기능

### 트랙패드 제스처 (기본 꺼짐)

- **에지 슬라이더** — 트랙패드 오른쪽 에지를 두 손가락으로 위아래로 밀면 볼륨이 조절됩니다. HUD에 ▲/▼가 표시됩니다.
- **탭·스와이프 제스처** — 여러 손가락 탭과 스와이프를 워크플로우·단축키·메뉴 항목·시스템 액션에 연결할 수 있습니다.
- **미리보기** — 설정 화면에서 손가락 위치와 인식 상태를 실시간으로 확인할 수 있습니다.
- 스크롤 억제는 기존 **손쉬운 사용** 권한을 재사용합니다. 별도 승인 창은 없습니다.
- 사이드바 **도구 → 트랙패드**에서 토글을 켜야 동작합니다.

### 실행 가능한 액션 21종 추가 (카탈로그 154종 중 73종 구현)

- **이미지 인식** — `텍스트 인식(OCR)`·`QR 코드 스캔`·`동물 인식`. 파일 경로를 지정하거나 비워 두면 클립보드 이미지를 사용합니다.
- **언어·수치·날짜** — `언어 감지`, `측정`(길이·질량·온도·부피 단위 변환), `날짜 조정`, `날짜/시간 입력`.
- **대화상자** — `대화상자`(텍스트 입력), `확인 가져오기`(확인 시 `true`, 취소 시 `false` 출력), `빠르게 보기`.
- **프로세스·데이터·파일** — `잠자기 방지`(ApexKey 종료 시 자동 해제), `딕셔너리 가져오기`(JSON/plist, 점 표기 중첩 키), `리스트 동작`(선택 가능한 액션 목록), `출력 저장`(상위 폴더 생성·덧붙이기).
- **시스템 프리셋 7종 승격** — `스크린샷`·`새 메모`·`새 빠른 메모`·`배경화면`·`화면 깨우기`·`앱을 앞으로`·`다크 모드`를 이제 개별 액션 행에서 바로 선택·실행할 수 있습니다.

## 수정

- **카탈로그 정직성** — 시스템 동작으로 이미 실행되던 7종이 "준비 중"으로 보이던 문제를 고쳤습니다.
- **중복 액션 정리** — `스크린샷 찍기`(→ `스크린샷`), `클립보드 텍스트`(→ `클립보드 가져오기`/`클립보드 설정`)가 두 번 보이지 않습니다.
- **OneDrive 표시 이름** — OneDrive 액션이 다른 드라이브와 같은 이름으로 표시되던 문제를 분리했습니다.
- **트랙패드 방향** — 좌표계 뒤집힘으로 위로 밀면 볼륨이 내려가고 미리보기 점이 반대로 움직이던 문제를 수정했습니다.
- **트랙패드 인식** — 두 손가락이 조금 벌어져 있어도 인식되며, 한 번에 여러 칸씩 튀지 않도록 스텝을 14%·프레임당 1스텝으로 조정했습니다.

## 설치 방법

1. 아래 `ApexKey-1.6.0-macOS.dmg`를 다운로드합니다.
2. DMG를 열어 ApexKey를 응용 프로그램 폴더로 드래그합니다.
3. 첫 실행 시 **우클릭 → 열기**로 실행하세요.
   (공증되지 않은 앱이라 Gatekeeper가 첫 실행을 차단합니다.)

## How to install

1. Download `ApexKey-1.6.0-macOS.dmg` below.
2. Drag ApexKey to Applications.
3. On first launch, **right-click → Open**.
   (Gatekeeper blocks unsigned apps on first launch.)

## 알려진 제약 (릴리스마다 포함)

> 배포본이 코드 서명·공증되지 않은 상태라 사용자가 반드시 겪는 동작입니다.
> 매번 복사해 넣으세요. 서명 도입 시 이 절을 삭제합니다.

### ⚠️ 릴리스는 코드 서명·공증되지 않았습니다

- **첫 실행 차단** — Gatekeeper가 앱을 막습니다. **우클릭 → 열기**로 우회하세요.
- **업데이트마다 접근성 권한 재승인** — 새 버전 설치 후에는
  시스템 설정 → 개인정보 보호 → 손쉬운 사용에서 ApexKey를 다시 켜야 합니다.
  macOS가 접근성 권한을 앱의 코드 서명(CDHash)에 묶어 두는데, 무서명 앱은 버전마다 이 값이
  바뀌어 권한이 자동 해제되기 때문입니다. Developer ID 서명·공증으로 해결됩니다.
- **트랙패드 제스처는 기본 꺼짐** — 설정 → 트랙패드에서 직접 켜야 합니다.
